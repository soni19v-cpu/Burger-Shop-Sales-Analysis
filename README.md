An interactive Power BI dashboard created to analyze burger shop sales data and generate meaningful business insights through data visualization.

Tools Used

Power BI

Power Query


Key Features

Sales KPIs (Revenue, Orders, Avg Sales)

Monthly & daily sales trends

Top-selling products analysis

Category-wise revenue breakdown

Interactive filters and slicers


Insights

A few products contribute to most of the revenue

Higher sales observed during weekends and peak hours

Time-based trends impact overall performance
